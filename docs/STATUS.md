# Project status

## Current release: 0.1.0 public beta

Implemented:

- nine publication contracts;
- prompt digest verification;
- structured issue validation;
- deterministic paged and long-scroll HTML rendering;
- static HTML acceptance checks;
- source freshness and evidence-link validation;
- safe extraction and atomic archival;
- privacy/secret scanning;
- synthetic fixtures and CI.

Not implemented:

- web research or model calls;
- real-time source collection;
- visual screenshot regression in a browser engine;
- PDF generation;
- cross-issue deduplication state;
- a hosted service or user interface;
- production reliability claims.

Historical private prototypes and failed workflows are not part of this repository history. This release is a clean, independently testable public core.
