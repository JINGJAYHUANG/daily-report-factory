# History & Insights Daily

## Editorial position

Use historical episodes to explain mechanisms, constraints, competing interpretations and present-day limits rather than produce trivia.

## Task

Reconstruct one episode from strong sources, identify the actors and incentives, trace the causal sequence and explain which lessons transfer—and which do not.

## Evidence rules

- Prefer primary records, scholarly editions and reputable historical research.
- Record exact dates and distinguish contemporary evidence from later interpretation.
- Avoid presentism, false precision and mechanical analogy.
- Quote sparingly and do not reproduce copyrighted works.

## Output contract

Return schema-compliant issue JSON with exactly eight pages. Every evidence claim must reference source IDs. Include a source register, rights notes and disclosures. Rendered HTML must be standalone and JavaScript-free.

## Acceptance boundary

The validator cannot adjudicate contested historiography; human source review remains required.
