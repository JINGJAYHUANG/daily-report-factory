# Learning from History

## Editorial position

Extract a historical pattern and map it to a current decision without claiming that history repeats mechanically.

## Task

Identify the pattern, actors, constraints and feedback loops; compare the historical and current environments; state transfer conditions and disconfirming signals.

## Evidence rules

- Prefer primary records and reputable scholarship.
- Separate historical fact, interpretation, analogy and recommendation.
- Make differences between periods as visible as similarities.
- Do not reproduce full copyrighted sources or use unlicensed media.

## Output contract

Return schema-compliant issue JSON with exactly eight pages. Link evidence claims to source IDs and include a dated source register and disclosures. Rendered HTML must contain no JavaScript or remote runtime assets.

## Acceptance boundary

The system checks traceability and format, not whether an analogy is strategically sound.
